# 민법2 중간고사 노트 — 학습 뷰어

옵시디언으로 쓴 `source/민법2-중간고사.md`를 읽기 좋은 HTML 학습 도구로 바꾼 것입니다.
원문 텍스트는 하나도 빼지 않고 그대로 보존합니다(`npm run verify`로 확인).

## 여는 방법
- **claude.ai 비공개 링크(권장)**: PC와 아이패드에서 같은 링크로 열면 하이라이트·빈칸·메모·필기가 계정에 저장되어 기기 사이에 자동 동기화됩니다.
- **`index.html` 파일**: 브라우저로 바로 열면 됩니다(인터넷 없이도 동작, 글꼴만 기본 글꼴로 대체). 이 경우 기록은 그 기기의 브라우저에만 저장되므로 설정(⋯) → 백업 내보내기/가져오기로 옮깁니다.

## 기능
| 모드 | 할 수 있는 것 |
| --- | --- |
| 일반 | 자동 스크롤(0.25×–5×), 하이라이트 5색·지우개, 메모(오른쪽 여백 카드, 좁은 화면은 배지 → 팝업) |
| 빈칸 | 단어/구간을 빈칸으로 가리기, 탭하면 공개·다시 가림, 모두 가리기/보이기 |
| 필기 | 검정·파랑·빨강 펜, 굵기 3단계, 되돌리기/다시 하기, 획 지우개, 전체 지우기 |
| 중요 | 하이라이트·메모가 있는 블록을 쟁점(제목 경로)별로 모아 보기, 색·종류 거르기, 원문으로 이동 |

- 왼쪽 목차(접기/펴기, 항목별 트리 접기, 검색)와 상단 현재 위치(상위 쟁점 경로) 표시
- 단어 중간을 누르거나, 한 단어 중간에서 다른 단어 중간까지 끌어도 **단어 전체 단위로** 적용
- 아이패드: 애플펜슬 = 필기·선택, 손가락 = 스크롤(손가락 탭은 가린 빈칸 열기). 설정에서 손가락 필기도 켤 수 있음(이때 스크롤은 두 손가락)
- 상단 "빈칸 가리기" 토글은 모든 모드에서 동작(빈칸 모드에 들어가면 자동으로 켜짐)
- 하이라이트·메모·필기는 모든 모드에서 보이며 새로고침·재실행 후에도 유지
- 단축키: `1`–`4` 모드, `[` 목차, `B` 빈칸 가리기, `P` 자동 스크롤, `+`/`-` 속도, `Ctrl/Cmd+Z` 되돌리기, `Esc` 도구 해제

## 다시 만들기
```bash
npm install
npm run build    # index.html, dist/artifact.html 생성
npm run verify   # 원문 텍스트 누락 검사
npm test         # Playwright 스모크 테스트
```
- **변환 범위**: 채권양도 파트의 `### 다. 채권양도계약이 해제/취소된 경우`부터는 미완성이라 제외했습니다. 노트를 완성하면 `build/build.mjs`의 `CUT_AT`을 `null`로 바꾸거나 다음 미완성 지점으로 옮기고 다시 빌드하세요.
- **이미지**: 원본의 `![[Pasted image ….png]]` 7개는 파일이 없어 자리표시로 나옵니다. 같은 이름의 파일을 `images/`에 넣고 다시 빌드하면 자동으로 들어갑니다.
- 블록마다 텍스트 해시로 id를 붙여서, 원문 일부를 고쳐 다시 빌드해도 나머지 부분의 하이라이트·메모·필기는 그대로 붙어 있습니다.
